# Settlr Design System

Repo-native design source for Settlr: a calm, Nepal-first shared-expense experience with global currency support. The Storybook catalog is the reviewable visual reference for web and React Native Web components.

Run `npm install` then `npm run storybook`. Build with `npm run build-storybook`.

Packages are scoped to `@settlr-org` and are intended for private GitHub Packages releases.
